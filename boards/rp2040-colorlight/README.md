# Atari 800 — RP2040 + Colorlight base board

Shared base board taking **either** a Colorlight **i5 / i9 (ECP5)** or **i9+ (Artix XC7A50T)**
SODIMM module (U4). RP2040-STAMP supervisor (U1) + HDMI + 2× DB9 joystick + microSD + 2× USB-A
host + native USB + audio + optional 1 Mbit SRAM (U10). Design source: the `Netlist_*.enet`
EasyEDA export in this folder.

The Colorlight i5 / i9 / i9+ module pinouts and schematics are from
[wuxx/Colorlight-FPGA-Projects](https://github.com/wuxx/Colorlight-FPGA-Projects).

## Building for a specific board (CLI switches)

### Supervisor firmware (RP2040)
```
cmake -DBOARD=colorlight ..   # this board (default)
cmake -DBOARD=qmtech ..       # legacy QMTech / SD-direct pinout
```
`BOARD` maps to a `BOARD_<UPPER>` compile define selecting the RP2040 pin map in
`sd_spi.c` / `main.c` / `blaster.c` / `jtag.c`. Both targets build.

**RP2040 pin map (colorlight):**
| Function | GPIO |
|---|---|
| USB host ×2 (PIO) | 0–3 → J4 |
| microSD (**SPI0**) | CIPO 4, CS 5, CLK 6, COPI 7, **CD 8** → J8 |
| FPGA link (**SPI1**) | SCK 10, MOSI 11, MISO 12, CS 13 (spare: 9, 14–21) → U4 |
| JTAG (bit-bang) | TCK 22, TMS 23, TDI 24, TDO 25 → J5 + module pads |
| Paddle POT (ADC) | 26–29 → J1/J2 |

*(NB: the board routes JTAG as TCK=22/TMS=23 — swapped vs GPIO0-3 — so the blaster PIO pin
order may need a runtime tweak.)*

### FPGA constraints (`fpga/`)
Generated from the netlist (`fpga/` regenerated by the netlist-parse script):
- **`pinmap.csv`** — master map: SODIMM pin ↔ net ↔ ECP5 ball ↔ Artix ball (69 signal pins).
- **`i5.lpf`** — ECP5 (nextpnr) constraints; HDMI as LVCMOS33 pseudo-diff.
- **`i9plus.xdc`** — Artix (Vivado) constraints, LVCMOS33.
- **`fit/`** — pin-validity fit-check (`boardpins_fit.sv` + `fit_i5.lpf`).

**Pin validity — verified:**
- **i5 (ECP5):** `nextpnr-ecp5 --25k --package CABGA381 --speed 6` placed all 69 as `TRELLIS_IO`
  (35 %), routing complete — every assigned ball is placeable I/O.
- **i9+ (Artix):** all 69 balls are general-purpose user I/O (Vivado package-pin set).

**HDMI TMDS → SODIMM (both modules):** CLK 71/69, TX0 83/79, TX1 99/95, TX2 109/111. See the
[i9+](../i9plus-6v1/README.md) and [i5](../i5-7v0/README.md) READMEs for the per-chip TMDS
inversion and the JTAG header pad coordinates.

## Netlist review — status
- ✅ HDMI wiring correct; **ESD (D1/D2) on the connector side**; JTAG per-module contact pads
  (`i5_*` / `i9+_*`) in parallel on TCK/TMS/TDI/TDO + J5; RP2040 fully remapped, no conflicts;
  SD on hardware SPI0 with card-detect; optional SRAM (U10) → FPGA.
- 🚩 Open before fab: **HDMI +5 V** needs a ferrite + ~150 mA polyfuse; **USB-A VBUS** wants its
  own current limit; **declare the 4 TMDS pairs** as length-matched 100 Ω in the PCB tool.
